The Excel sheet demonstrates the following functions:
1. TODAY() – Returns the current date.
2. NOW() – Returns the current date and time.
3. WEEKDAY() – Returns the weekday number.
4. DAY() – Extracts the day from a date.
5. MONTH() – Extracts the month from a date.
6. YEAR() – Extracts the year from a date.
7. DATE() – Creates a date from year, month, and day values.
